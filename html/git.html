Терминал macOS и команды Git

Основные команды Git

  • git init – Инициализация нового репозитория Git.
  • git clone – Клонирование репозитория из удалённого источника.
  • git add – Добавление файлов в индекс для следующего коммита.
  • git commit – Создание коммита с изменениями.
  • git push – Отправка изменений в удалённый репозиторий.
  • git pull – Извлечение и объединение изменений из удалённого репозитория.
